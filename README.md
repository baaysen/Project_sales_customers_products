📌 Introduction

This project is an exploratory data analysis (EDA) and visualization of a sales dataset sourced from Kaggle. The dataset contains information about sales transactions, customers, and products, allowing us to uncover key insights and trends.

📂 Dataset

Source: Kaggle Sales, Customers, and Products Dataset

Contents: Sales transactions, customer details, and product information.

Format: xlsx files

🎯 Objectives

Perform data cleaning and preprocessing

Conduct exploratory data analysis (EDA)

Generate visualizations for key insights

Identify patterns in customer behavior and sales trends

Draw meaningful business conclusions

🛠️ Tools & Technologies

Python (Pandas, NumPy, Matplotlib, Seaborn, plotly)

Jupyter Notebook for analysis

Git & GitHub for version control

📊 Key Insights

Some of the key findings from the analysis include:

Top-selling products and their revenue contribution

Customer segmentation based on purchasing behavior

Seasonal trends in sales performance

Etc..
